Servidor NFS e demanda de espaço compartilhado

Em um ambiente educacional de excelência é necessário disponibilizar ferramentas á altura dos desafios acadêmicos.

Para matérias que requerem alta disponibilidade de armazenamento (para fins de machine learning, criação/configuração de máquinas virtuais e criação de agentes de IA) foi demandado um espaço compartilhado para usuários de uma rede específica de computadores, para solucionar o problema foi disponibilizado dois SSD's de 1TB para essa rede, e com isso, foi estudada a implementação de um servidor NFS para realizar esse compartilhamento eficiente em máquinas Linux Ubuntu.

essa branch tem como objetivo expor como realizei a configuração da maquina que irá servir como servidor e também das máquinas clientes que irão consumir o espaço compartilhado.
